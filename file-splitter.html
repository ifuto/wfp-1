📦 ファイル分割ツール

大きなファイルを指定サイズ以下のパートに分割します。処理はすべてブラウザ内で行われ、ファイルはどこにも送信されません。

① ファイルを選択

タップしても選択画面が出ない場合は… を直接タップ。それでも開かないときは、共有メニューの 「Safariで開く」 で開き直してね。

② 分割設定

iOS 一括保存モード

共有シートが開いたら 「“ファイル”に保存」 をタップ → 保存先（「ダウンロード」など）を選んで保存 → このページに戻って次のボタンをタップ、の繰り返しです。

③ ダウンロード / 保存

⚠️ ブラウザが「このサイトで複数のファイルのダウンロードを許可しますか？」と尋ねてきたら「許可」を選んでください。 パートと manifest.json はセットです。分割し直した場合は両方とも保存し直してください。

（参考）手元で結合する場合

Linux / macOS（WSL可）: cat ファイル名.part*.bin > 元のファイル名.zip
Windows: cmd /c copy /b part001.bin+part002.bin+... out.zip
