ℹ️ 仕組み

アップロードした .wfpbundle をブラウザ内でzip展開 → timeline.wesproj のカット情報を解析 → 素材（AV1/H.264）を WebCodecs でデコード → キャンバスでスケール → H.264に再エンコード → 音声は WebAudio でミックス → MP4に多重化。全工程ローカル実行・送信ゼロ。 中断してもセグメント（クリップ）単位で再開…はせず、最初からやり直しになります（ごめん！）。
