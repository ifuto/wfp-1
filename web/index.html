ℹ️ 仕組み

分割アップロードされた31パート（/files/*.bin）を HTTP Range で必要分だけ取得してzip解析 → timeline.wesproj のカット情報を解析 → 素材を抽出 → ffmpeg.wasm（ブラウザ内ffmpeg）で セグメント化→連結→音声ミックス→書き出し、まで全部ブラウザ内で実行します。ファイルはどこにも送信されません。 ローカルモードなら手元の .wfpbundle を直接開けます（ページをダウンロードしてオフラインでも可）。
